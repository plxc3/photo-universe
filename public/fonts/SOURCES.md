# Self-hosted fonts

Downloaded on 2026-10-23 from the official Google Fonts delivery service. All three files are Latin variable WOFF2 fonts and can be served locally with the accompanying fonts.css. Retain the OFL text when redistributing the fonts.

| File | Style | Weight | License |
| --- | --- | --- | --- |
| newsreader-latin-variable.woff2 | Newsreader normal | 200–800 | Newsreader-OFL.txt |
| newsreader-latin-italic-variable.woff2 | Newsreader italic | 200–800 | Newsreader-OFL.txt |
| manrope-latin-variable.woff2 | Manrope normal | 200–800 | Manrope-OFL.txt |

Newsreader is by Production Type: https://github.com/productiontype/Newsreader
Manrope is by the Manrope Project Authors: https://github.com/googlefonts/manrope

Official license sources:

- https://raw.githubusercontent.com/google/fonts/main/ofl/newsreader/OFL.txt
- https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/OFL.txt

Direct font-delivery URLs, file sizes and SHA-256 values are in manifest.json. These Latin subsets do not provide Chinese glyphs; use system CJK fonts as fallback. No runtime connection to Google Fonts is required.
